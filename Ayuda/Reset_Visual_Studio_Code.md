# El botón de pánico -  Reiniciar el Servidor de Lenguaje (Sin salir de VS Code)

* Presiona Ctrl + Shift + P (o F1) para abrir la paleta de comandos de VS Code.
* Escribe exactamente: ``Restart TS Server`` (Reiniciar servidor TypeScript/JavaScript).

Selecciona esa opción y dale a Enter.

Verás un pequeño mensaje abajo a la derecha que dice que se está reiniciando. Al instante, vuelve a tu archivo, borra la última letra, presiona Ctrl + Espacio y verás que responde con total fluidez.
